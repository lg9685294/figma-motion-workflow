# 制作、修复与撤回指令

安装 Skill 后，根据本轮目标选一段，补上实际节点和素材。不要把案例数值当作新项目默认。

## 首轮制作

```text
使用 $figma-motion-workflow。
目标文件与节点：【实际链接】。
素材：【源SVG、最终选中态、参考视频】。
希望表达：【动作含义】，触发方式：【点击／悬停／其他】。
先整理有效参数和未知项，再核对最终几何、拆层与编排依赖。
有编辑能力时在可恢复副本中制作，正常速度与逐帧分别验收。
交付实际节点、参数、可用预览和待补项。
```

## 定点修复

```text
使用 $figma-motion-workflow，只修复【节点】在【时间／进度】的【问题】。
依据【源路径／截图】，目标是【具体可观察结果】。
本次修改：【属性、旧值、新值】。
保留其他已接受动作；重算相关依赖与整段结束，同步参数表。
检查修改前后、阈值附近与最终稳定帧，回报实际改值和验证结果。
```

## 只撤回本轮试验

```text
使用 $figma-motion-workflow，撤回【明确的一次变更】。
恢复其修改前的属性和依赖时序，保留【其他已接受改动】。
回报恢复字段、仍生效字段、整段结束及待核验项。
```

## 只做时序检查

```text
使用 $figma-motion-workflow。只分析【时序规格／对话记录】，不修改Figma。
明确时间原点、真实曲线与驱动属性，计算阈值与全部轨道最后终点。
缺少曲线或阶段参数时保留待核验，不补造精确总时长。
```
