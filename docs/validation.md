# 验证范围

本页区分历史试用、2026-11-06 的本地检查和仍未验证的能力。本地检查结果不代表 GitHub Actions 的运行状态；云端记录请查看 [Actions](https://github.com/lg9685294/figma-motion-workflow/actions)。

## 计时与规格

- 计时脚本的 17 项测试覆盖：非线性阈值反求、两级依赖、父阶段变更后的重排、并行轨道最大终点、未知曲线、循环和重复依赖、非法数字与总长冲突。
- 示例 `timing-spec.json` 的完整终点约为 752.13338184ms；“路径到90%”触发约为 322.13338184ms。
- 输入只有曲线名称时，脚本不会将其映射成猜测的曲线。

2026-10-31 用两个没有提供预期答案的新请求试用工作流：

这些试用验证计算和文字规格行为，没有连接 Figma 验证真实制作。
