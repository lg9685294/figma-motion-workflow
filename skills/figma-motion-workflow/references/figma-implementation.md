# Figma 实现与能力路由

## 先发现实际能力

官方路径与工具说明复核日期：2026-11-06。产品和工具会变化，执行时以已连接工具及官方说明为准。不要在脚本中编造 API 名称或将一种代理的能力表套到另一种接口。

| 本轮任务 | 优先路线 | 验证依据 |
| --- | --- | --- |
| 读取源图形与视觉 | Figma 设计上下文、源矢量、截图 | 当前节点属性与截图 |
| 读取已有关键帧 | 暴露时使用 motion context | 轨道、曲线和时间，不靠静态截图猜测 |
| 写入可编辑节点 | 可用的写画布接口或已授权 UI | 回读新节点与实际属性 |
| 精确路径生长 | Motion Path trim／符合几何的揭示方法 | 指定进度的路径外观和最终同一路径 |
| 变体及导航交互 | 原型界面或明确支持的接口 | 实例中点击、重播与切换 |
| 视频／资产交付 | 可用导出接口或已授权 UI | 实际存在并能打开的文件 |
| 没有相应执行能力 | 完成规格、制作提示词与手动步骤 | 清楚注明执行与验证状态 |

官方 MCP 文档给出的读动效路线是先取设计上下文，再对同一节点读取动效上下文；可读取子层时按需要递归。写画布工具与网页捕获工具作用不同，网页被导入为图层不证明已经保留了关键帧。[工具说明](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/)

Figma 内置 Agent、外部 MCP 和 UI 自动化分别检查能力。执行前查阅实际接口及 [Agent 能力表](https://help.figma.com/hc/en-us/articles/37998629035799-Work-with-the-Figma-agent-in-design-files)，再确认能否处理几何、Motion、原型和导出。工具能力会更新，已有连接不等于所有操作都可用。

## 路径、旋转和状态

- Motion Path trim 适用于居中描边。Path 预设使用开放路径；trim 关键帧可处理开放和闭合路径。先核查源图形是描边还是已经扩展的填充轮廓，再选实现方法。[Path trim](https://help.figma.com/hc/en-us/articles/42200302811927-Animate-strokes-with-path-trim)
- 填充轮廓需要揭示时，保留最终原形，通过合适的遮罩逐步显示；这是实现策略，需要验收交点、端帽和接口，不能承诺所有形状都适用一个矩形遮罩。
- 多部件共用运动父组或一致参照系，检查旋转中心、缩放中心和渐变坐标。接口不能在第一帧或运动中脱开。
- Motion rotation 可用 0°→360° 编排完整一圈；以预览确认方向。传统状态过渡的同外观首尾不能证明转过一圈。[旋转教程](https://help.figma.com/hc/en-us/articles/41523077992855-Motion-design-fundamentals-Create-a-loading-animation)
- Smart Animate 依靠层名和层级匹配，并支持特定属性过渡。复杂描线或任意路径形变需另选路线；淡出可以保留图层并改变不透明度。[Smart Animate](https://help.figma.com/hc/en-us/articles/360039818874-Smart-animate-layers-between-frames)
- 变体交互与实例覆盖可能影响点击结果；在实际实例中测试。[交互组件](https://help.figma.com/hc/en-us/articles/360061175334-Create-interactive-components-with-variants)
- After delay 是时间延迟，不是路径百分比监听器。先按真实曲线算阈值时间，再编排可用状态或轨道。[触发器](https://help.figma.com/hc/en-us/articles/360040035834-Prototype-triggers)

## 提示词模板

仅在需要把任务交给另一个制作环境时使用；有当前可用编辑能力时，直接制作并验证。替换模板变量，移除无关项。

### 首轮生成／参考复刻

> 在【目标文件与节点】制作【图标／组件】的【触发行为】动效。使用【源矢量与参考文件】，保留源稿和上一接受版本。以【有效参数表】作为本轮规格；建议值与待核验值分别列出。
>
> 先核对静态最终轮廓、孔洞、线宽、端帽、接口和渐变，再拆主体、可生长路径与辅助部件。起点为【交互启动】，预滚为【无／数值】；依赖关系为【事件图】。阈值按【实际驱动属性】及真实曲线换算。末帧保留同一套几何。
>
> 先制作主体与状态交接，再加局部动作；按【关键时间／进度】截图和实际播放验收。回报可编辑节点、有效参数、已验证预览及待补项。若环境不支持某项操作，完成可执行部分并说明缺少的能力。

### 定点修复／改时长

> 只修复【节点】在【时间／进度】出现的【可观察问题】，依据【源路径／截图／参考】。目标为【无缝接口／无尖刺／方向正确／节奏等具体结果】。本次改动为【属性：旧值→新值】。保留其他已接受动作；重算受影响的下游事件和整段结束，同步参数表。验收修改前后、阈值附近和最后稳定帧。

### 撤回试验

> 撤回【明确的试验／变更记录】，恢复其修改前的属性及依赖时序。保留【其他已接受改动】。回报恢复字段、仍生效字段和重新核验的整段结束；同一节点的名称不足以作为历史版本依据。
