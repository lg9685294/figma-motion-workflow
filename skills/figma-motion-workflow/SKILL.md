# Figma 动效工作流

把参考与需求转成可追踪的动效规格，按当前可用能力制作，并用真实播放验证。沿用项目已有组件、图形和视觉语言。需要图标案例时读取 [匿名 Tab Bar 案例](references/tabbar-case.md)；其中的具体参数仅用于该案例。

## 先确认交付和能力

从用户现有材料推断本轮目标：首轮生成、参考复刻、局部修复、参数调整或撤回。确认交付对象是 Figma 可编辑节点、原型、视频、规格还是制作提示词。用户已明确的目标直接执行。

- 先发现当前工具。能读 Figma 不代表能写动画、连原型或导出；逐项记录可读／可写／可验证范围。
- 若有 Figma 接口，读取当前目标结构、图形与截图；支持读取动效时再取时间轴。大节点返回截断时，缩小到实际部件。
- 有编辑能力：在目标文件内保留可恢复副本，按已授权范围制作、回读并验收。工具调用参数以实际说明为准。
- 仅有读取或聊天能力：完成素材清单、有效规格、分层方案、可直接交给 Figma Agent 的提示词及待执行项；清楚标注尚未在 Figma 执行。
- 缺少源路径、真实曲线等关键输入时，继续独立可做的拆解与规格；无法读取的关键项保持待核验。若其决定制作结果，再集中询问。

具体工具选择和实现路线见 [Figma 实现](references/figma-implementation.md)。不将某次连接失败固化为产品永远不支持。

## 1. 收拢素材与生效需求

为原始矢量、参考录屏、截图、参数画板和提交物记录来源、文件或节点标识、版本以及获取状态。区分原文件、导出物、截图和仅有链接。分享页附件占位不代表已取得附件；同一节点改名不代表保存了独立历史版本。

从迭代对话建立按属性的变更记录：目标 → 原值 → 新值 → 单位 → 依据 → 影响的依赖。最新明确修改只覆盖它针对的属性；“撤回这次”恢复本次变更及其依赖，保留其他已接受调整。

参数使用以下状态：`confirmed` 明确确认；`carried` 早期明确且后文未改；`derived` 依据已知关系推算；`proposed` 制作建议；`unresolved` 缺输入。另记录 `superseded`、`reverted` 历史，不把助手的“已完成”当作本轮实测证据。

录屏测量保留事件定义、有效帧率与误差。点击、滚动、悬停、加载状态分别拆解；没有展示的状态不补写为参考事实。无法定位触点时，使用“首次可见变化”作为测量起点并写明，不能声称那就是实际点击时刻。

## 2. 锁定几何和运动语义

先核对未选中态与最终选中态的轮廓、孔洞、线宽、端帽、接口、渐变坐标和旋转中心，再加动作。使用原始矢量；仅有截图而需要重建时明确标注重建及误差。

按实际独立运动拆为：旧形态、主体、可生长路径、辅助部件和稳定层。底托、文字和角标是否运动由设计决定。多个图标共享交接节奏，各自的局部动作表达功能含义。

做路径起点与方向的小进度预览；连接的部件应在相同运动参照系下保持接口与渐变连续。生长应揭示最终原始轮廓，完成后停留在同一套几何；修复末帧跳变时检查过程用的路径与最终路径是否相同。

## 3. 建立事件依赖与时间口径

按 [规格与计时](references/spec-and-timing.md) 定义每条轨道：对象、属性、起终值、开始事件、时长、曲线、来源状态。

- 默认以交互启动为 `t=0ms`。预滚单独记录：`timeline_ms = t + preroll_ms`；项目没要求就不加预滚。另记参考视频的时间原点。
- “路径实际长到 90%”是属性阈值。若进度为 `E(u)`，触发时间为 `a + d × E⁻¹(q)`；只有 Linear 才能用 `d × q`。
- 读取真实曲线控制点或采样数据；只有 Ease Out 名称时不擅自套用 CSS 同名曲线。显现同时改变多个属性时，指定哪个属性定义阈值。
- 修改时长、曲线、路径或触发条件后，重算所有下游事件。整段结束取全部可见轨道结束时间最大值，包括回弹、停留、眨眼、回落和回正。
- 指定整段结束时间时核对各轨道，出现冲突则修正相关依赖或标出冲突；不能仅改总时长标签。

可用标准库辅助脚本做精确的单调曲线换算与事件审计。下列路径以本 `SKILL.md` 所在目录为基准；实际执行使用 skill 的绝对路径，不假设用户当前目录就是 skill 目录。项目规格保存到当前项目，保留 skill 模板：

```bash
python3 scripts/timeline.py threshold --start-ms 100 --duration-ms 300 --progress 0.95 --easing 'cubic-bezier(0,0,0.58,1)'
python3 scripts/timeline.py audit assets/timeline.example.json
```

以上曲线与数值仅演示输入格式。脚本不能验证 Figma 图形、实际播放或轨道清单是否完整；弹簧、多次越阈值及未指定曲线需使用源数据另行核验。

## 4. 分层制作并保留修改边界

先完成旧形态交接和主体动作，再加局部路径与表情；每一步对照源几何。优先沿用现有组件和样式，避免在调时序时重绘图标。

- 精确描线及多属性编排：当前环境支持时用 Motion 时间轴与路径属性。
- 状态切换：按实际能力配置变体和原型。Smart Animate 的层名与层级需对应，不假定它能完成任意矢量形变。
- 局部修复：明确图标、节点、时间／进度、问题和验收帧；只改相关属性及依赖，保留已接受动作。
- 输出提示词时写清目标节点、源素材、有效参数、几何约束、依赖和验收要求；未知值保留待核验。可用 [提示词模板](references/figma-implementation.md#提示词模板)。

涉及代码预览时采用可定位到指定时刻的确定性时间轴；只有用户要求代码或视频交付时才采用相应运行时，生成的预览单独标注实现环境。

## 5. 实际播放、逐帧检查与交付

按 [验收与修复](references/qa-and-iteration.md) 正常速度检查节奏，再检查起笔首帧、交点、阈值前后、结束前后和稳定帧。实际显示尺寸看抖动与可读性，放大看几何。

分别核验源时间轴、视觉播放、交互重放和输出文件。静态截图只能证明静态外观；没有播放证据时保留动态项待验收。多轮修复仍重复同一问题时，回到源路径或参照系定位原因；外部写入失败先回读状态再重试，避免重复创建。

按任务规模交付：可用的 Figma 节点／源文件、有效参数表、已有预览和简短验收记录。保存实际收到的素材与必要来源索引。清楚区分本轮改动、已验证结果、推算值及待补项；未生成或未下载的文件只保留引用。
